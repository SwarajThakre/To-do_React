# ✅ React To-Do App

![React](https://img.shields.io/badge/React-61DAFB?style=for-the-badge&logo=react&logoColor=black)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![Responsive Design](https://img.shields.io/badge/Responsive-Design-0A66C2?style=for-the-badge)

A responsive and interactive **To-Do List application built with React.js**. The application allows users to add, manage, complete, edit, and delete tasks through a clean and user-friendly interface.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📋 Display and manage tasks dynamically
- 📱 Responsive design
- ⚡ Fast and interactive UI
- 🎨 Clean and user-friendly interface
- 🔄 Real-time UI updates without page reloads

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/SwarajThakre/react-todo-app.git
```

### 2. Navigate to the project directory

```bash
cd react-todo-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the application.

---

## 💻 Usage

1. Enter a task in the input field.
2. Click the **Add** button to create a task.
3. Mark a task as completed when finished.
4. Edit tasks when changes are required.
5. Delete tasks that are no longer needed.
